# Claude Code: start here

This is the owner's **remaster fork** of GauntletDLRedone. Before doing
anything else, read `docs/remaster/HANDOFF.md`. It covers the project state,
the owner's goals and preferences, how to build on Windows, the diagnostics,
the current task (the texture phase) and the roadmap.

Then follow the project rules in AGENTS.md:

@AGENTS.md

In this fork, remaster features are labelled NATIVE additions. They stay out
of `Settings::baseline()`, and they keep the original mode bit-identical. The
owner asked to be asked when anything is unclear, and is happy for you to
research on the web. Work on the `remaster` branch.
